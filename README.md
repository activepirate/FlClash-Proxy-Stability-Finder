# FlClash Proxy Delay Recorder

这是独立于 FlClash 的本机代理延迟记录工具。测试结果只在运行期间保存在内存中，并显示各代理的成功率、平均延迟和抖动；不修改 FlClash 项目，也不需要第三方 Python 包。

## 目录

- `app/`：采集逻辑和本机 Web 界面。
- `config/config.json`：本地控制器地址和密钥配置，已加入 Git 忽略规则。
- `config/config.example.json`：不含密钥的配置模板。
- `scripts/`：启动脚本。

## 准备

FlClash 中启用外部控制器并使用本机回环地址（默认 `http://127.0.0.1:9090`）。Web 界面提供四个出口 IP 检测服务，每次点击只访问当前选择的服务；另有“服务状态”模块，默认检查 Google、GitHub 和百度，也可以在页面中添加或删除自定义名称和 URL。出口 IP 检测直接访问对应服务，服务状态检测使用运行环境的常规网络配置（例如系统或环境代理）。在 Web 界面的“控制器密钥”字段输入密钥，保存后会写入本地 `config/config.json`。也可以直接编辑该 JSON 文件中的 `secret`。配置文件按当前系统支持的方式限制为仅当前用户可读写；密钥以明文保存在本机，请勿分享该文件。不要将控制器暴露到局域网或公网。

Python 3.10 或更新版本即可运行，无需安装第三方 Python 包或 Tkinter。浏览器会打开本机 Web 页面，服务仅监听 `127.0.0.1`。

## Web 界面

```bash
./scripts/start.sh
```

启动脚本会运行本机服务并打开浏览器（默认 `http://127.0.0.1:8765`）。界面可设置控制器地址、密钥、测试 URL、轮数、间隔、同时测试数和单次超时；刷新代理列表后，开始采集会按“同时测试数”并发测试当前列表中的代理。页面还显示控制器流量、日志和活动连接的实时数据。开始采集后逐项显示结果与实时汇总，数据只保存在内存中，支持停止。按 `Ctrl+C` 关闭服务。

如需手动打开浏览器，或希望服务不自动打开浏览器：

```bash
./scripts/start.sh --no-browser
```
